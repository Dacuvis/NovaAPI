# API + LUA CONFIG

This is a simple web API using Lua config.

## 🐭 Tech Stack

- **Runtime:** [Bun](https://bun.sh/)
- **Framework:** [Elysia.js](https://elysiajs.com/)
- **Scripting Language (Config):** [Lua](https://www.lua.org/) (via [Fengari](https://github.com/fengari-lua/fengari))

## 🐧 Setup & Installation

1. clone this repository and go to its project directory:
   ```bash
   git clone <this-repo>
   cd NovaAPI

2. Install all dependecies in this repo:
   ```bash
   bun install

3. Run the server
   ```bash
   cd src
   bun run index.ts
